Your job is to reverse-engineer and recreate the functionality of an ancient unobtainable software known as "SITV 1.08", based only on the data that went into it and the data it produced.

Use git for version control.

The data that went into it is located in the `input/` directory and the output data is in the `output/` directory.

`output/` contains only a portion of the full data, but `input/` contains all the data.

Your ultimate goal is to write the necessary Python project that can create something similar to the `output/` directory (but it can be better and more updated e.g. using .html instead of .htm. Files can also be a better format more suited to the data involved). The recreated data should contain at least all of the text data in`output/`, so you can use that as a reliable indicator. The image data is also there for comparing against (though it may not be in its truly-original form).
